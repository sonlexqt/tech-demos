# Apps

Each subdirectory is one **self-contained** tech demo.

- Folder name: **kebab-case** slug (e.g. `vector-toy`, `wasm-synth`).
- Run locally:

```bash
cd apps/<slug>
bun install
bun run dev
```

Cloud agents add one folder per approved pick. See root `AGENTS.md` and `skills/project-planning/SKILL.md`.
