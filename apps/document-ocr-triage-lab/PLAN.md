# Document extraction-check lab

## Source
- Approved Xberg extraction-check PoC; https://docs.xberg.io/
- Slug: `document-ocr-triage-lab`

## Goal
Compare real native-only extraction with automatic local Tesseract English OCR on three reproducible synthetic invoices. Show text, timings, diagnostics and separate known-answer evaluation in under two minutes.

## Out of scope
Production reliability guarantees, private data, paid APIs, remote models, deployment, authentication and general uploads.

## Stack
Bun server, plain browser UI, pinned native Xberg npm package, local Tesseract; Python Pillow/reportlab for reproducible committed fixtures.

## Manual testing / README
Document install/run, Tesseract English prerequisite, fixture generation, comparison clicks, expected native/scan behavior, errors, offline verification and diagnostic caveats. No browser flags or Agent panel required.

## Acceptance criteria
- Independently runnable via bun install && bun run dev.
- Native fields preserved; clean scan improves beyond disabled-OCR baseline.
- Known-answer missing fields counted separately from production telemetry.
- Errors explicit; network-disabled extraction verified.
- qualityScore described as retained-text cleanliness; missing confidence unknown.
- README and HOW_IT_WORKS explain transparent heuristic review rules.
- Screenshot and real captioned 60–100 second browser video included on draft PR.
- Final lint, typecheck, tests and browser QA recorded with exact runtime versions.

## Validation (PR)
Capture all comparison outcomes in evidence JSON; screenshot scan comparison. Record browser fixture selection, real extraction, diagnostics and ground-truth distinction with cursor/key indicators and readable pauses. Publish isolated branch and draft PR only; verify remote SHA.

## Completed validation
Native Xberg 1.3.5 and local Tesseract smoke passed. Five extraction tests, OS-network-blocked tests, lint, typecheck and browser assertions passed. Fixtures regenerated byte-identically. Final captioned browser video is 77.72 seconds, H.264, with full decode, real playback, nonblank-frame and interaction-indicator checks. Screenshots and evidence are included under `evidence/` for the draft PR.
