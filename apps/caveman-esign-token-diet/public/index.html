Two rocks, two claims

Author (JuliusBrussee/caveman): the output skill makes agents answer in short blunt lines while leaving IDs, paths, and errors verbatim. A newer local proxy shrinks what the agent reads. CaveBench reports 33.2% fewer provider input tokens on a pinned Claude Code suite (18/18 exact answers). That is the author's published benchmark, not an independent audit.

Skeptic: coding agents typically read 5–10× more than they write. Output-only trimming (the viral skill) cannot move most of the bill. Caveman's own HONEST-NUMBERS.md says the skill adds input, can go net-negative, and that a “be concise” control already captures most of the output cut. HTML in CaveBench got worse. Treat 33% as one measured mix, not a guarantee.
