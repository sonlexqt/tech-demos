## What the PR says
Lumin Sign–framed desk for [XERJ](https://github.com/xerj-org/xerj) (Apache-2.0). A messy envelope corpus is asked the same questions two ways: **grep** vs **XERJ ranked passages**, with a ground-truth answer key and measured byte/token counts.

## What reviewers get
- `apps/xerj-esign-search/` — `bun install && bun run dev` (offline fixtures, no binary, no keys)
- Six canned questions: countersign block, parties, expiry, failed reminder, MSA v1 vs v2, and the PageIndex-style Acme liability cap
- Side-by-side hits + correctness pills + file-bytes vs `_passage` bytes (tokens = bytes÷4, labeled estimates)
- Real captured `xerj autoindex` / `POST /esign-*/_search` + `_passage` / `xerj gain` (v1.0.0-rc.96). `xerj gain` reports counted searches, hit rate, and latency — it does **not** print a dollar savings figure on this build
- Honest CLI note: `xerj search` is the code/`defs` client and 400s on this docs corpus; the UI uses the documented ES `_search` + `_passage` path
- Live re-index/re-query is optional (`XERJ_LIVE=1`); keys never committed
- `PLAN.md`, `README.md` (run + manual test), `HOW_IT_WORKS.md` (indexing, ranking, MCP wiring, mermaid)
- Tracking: `gh-xerj-org-xerj` (https://github.com/xerj-org/xerj, GitHub trending) marked **proposed and built** in the same PR

## Honest findings from the capture
- Countersign: XERJ ranks `ENV-MSA-7F2C91-countersign.pdf` page 3 first (7.4× fewer payload bytes than opening grep’s matching files)
- Reminder failed: XERJ ranks `ENV-NDA-NORTHWIND` first
- Liability cap (same long-MSA style as `apps/pageindex-contract-qa` / PR #12, **not modified**): Harbor §8 outranks Acme 10.2.1 because both say “cap”. PageIndex would walk the TOC to 10.2.1. That ranking is real, not gamed.
- XERJ caveat (theirs): wins on private/niche/post-cutoff docs; neutral-to-harmful on memorized public libraries

## Validation
